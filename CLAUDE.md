# @supaproxy/redis

Redis session store adapter for SupaProxy. Implements the SessionStore port from @supaproxy/core.

See the [central hub](https://github.com/NumstackPtyLtd/supaproxy) for cross-repo governance.

## Structure
- `src/RedisSessionStore.ts` — SessionStore implementation
- `src/index.ts` — createRedisSession() factory

## Rules
- All changes go through PRs. Never push directly to main.
